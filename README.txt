HELLO, FUTURE
一份由你想像、送畀未來嘅數碼禮物
==================================================

點樣打開
--------------------------------------------------
直接雙擊 index.html，用較新版本嘅 Chrome、Edge、Safari 或 Firefox 打開。
唔使安裝任何套件，唔使開伺服器，亦唔需要連線。
正式交付畀 iPhone／微信用戶，請發 GitHub Pages 嘅 HTTPS 網址。
唔好將 HTML 當微信附件發送；iPhone 檔案預覽器唔等於瀏覽器。
網址第一次開啟需要連線，載入後嘅四幕操作同紀念卡生成唔需要外部服務。
冇安裝 Service Worker，所以唔保證斷網後重新整理網址仲可以載入。

檔案
--------------------------------------------------
index.html   完整網頁；所有樣式、圖像、文案同程式都已經內嵌。
README.txt   呢份使用說明。
原有嘅 README.md 保持不變。
.nojekyll   GitHub Pages 靜態發布標記；冇 Jekyll 或建置依賴。

點樣體驗（一般約兩至三分鐘，冇限時）
--------------------------------------------------
1. THE AWAKENING
   約六秒嘅星光開場；隨時可以撳「跳過開場」。
   撳開始按鈕，走進星空。

2. THE UNIVERSE
   揀 IMAGINARIA、MAKARIA 或 EXPLORIA 其中一個星球。
   四秒嘅過場會自動進入創作，亦可以撳「繼續」。

3. CREATE YOUR WORLD
   揀一個世界、一位主角同一種能力；每組都有預設選項。
   預覽會即時更新。揀好之後，撳「創造我嘅世界」。
   兩三秒後會見到世界名稱、完整景觀、故事同能力介紹。
   可以返回調整，再次創作；唔需要收集物件或完成任務。

4. A GIFT FOR THE FUTURE
   撳「將呢個世界送畀未來」，將創作變成紀念卡。
   寶寶稱呼可以留空；填寫時，紀念卡會即時更新。
   撳「保存呢份禮物」，製作 1200 × 1800 像素嘅 PNG 圖片。
   iPhone／微信：網頁會顯示完整高清圖片，唔會跳走。
   見到「長按圖片儲存到相片」之後，長按圖片，再揀系統嘅儲存圖片選項。
   英文提示：Press and hold the image to save it to Photos.
   電腦：同時嘗試下載；亦可以右鍵保存完整圖片，或撳「再下載一次」。
   呢張 PNG 可以獨立保存、列印同分享，唔需要網頁先睇到。

紀念卡內容
--------------------------------------------------
包括 HELLO, FUTURE、創作日期、出發星球、世界名稱、同一個幻想世界嘅
直幅構圖、主角、能力、英文祝福、香港粵語祝福，同可選嘅寶寶稱呼。
日期以創作嗰刻嘅香港時間為準；切換語言唔會改變創作日期。
唔同畫面比例會裁切部分景觀，但唔會拉伸星球或人物。

語言、鍵盤同音效
--------------------------------------------------
初次打開：英文視覺主文案，配香港粵語操作提示。
右上角 EN：主要介面、提示同創作結果改為英文。
右上角 粵語：改為香港繁體字同自然粵語。
紀念卡嘅英文同粵語祝福會同時保留；英文專有名稱亦會保留。
切換語言唔會重設星球、三種選擇、世界或寶寶稱呼。

可以用 Tab / Shift+Tab 移動焦點，Enter 或空白鍵操作按鈕；
選擇組內可用方向鍵切換選項。焦點會有清晰框線。
系統開啟「減少動態效果」時，頁面會停用動畫並縮短等待。

預設靜音。右上角音效按鈕可開啟或關閉輕柔嘅本地合成音效。
冇背景音樂，唔會下載或串流音訊。音效唔影響操作。

喺微信入面使用
--------------------------------------------------
先將 index.html 發布到 HTTPS 靜態網站託管，再將網址貼到微信。
朋友撳網址就可以體驗，唔需要下載 HTML。
微信內撳「保存呢份禮物」之後，會顯示完整 PNG 圖片；
頁面會明確顯示「長按圖片儲存到相片」。
使用真正嘅 <img>，冇阻止長按選單，唔依賴微信嘅檔案下載功能。
PNG 使用內嵌 data URL，唔依賴 Blob URL、Canvas.toBlob 或 FileReader。
程式會保持喺裝置本地生成紀念卡，唔會將稱呼或圖片上傳。
未喺真實微信裝置實測；瀏覽器模擬測試唔代表微信已認證該網址。

點樣創造世界
--------------------------------------------------
使用本地規則同預置文案，唔會呼叫 AI 或翻譯服務。
五種世界各有唔同地形：海洋、浮島森林、星際城市、機械花園同圖書館。
四位主角各有唔同外觀同故事行動。
五種能力會加入繁星、失重浮石、彩色光帶、發光植物或星座對話。
星球會影響景觀中嘅天體同色調。
共有 100 組世界／主角／能力組合，配合三顆星球，共 300 組視覺組合。
同一組選擇會得到一致嘅圖像，方便重看同保存。

相容性同已知限制
--------------------------------------------------
需要支援 Canvas 2D、Canvas.toDataURL 同 JavaScript 嘅瀏覽器。
視口優先用 100dvh，保留 100vh／innerHeight 回退；支援 safe-area。
已移除 Canvas.roundRect 依賴；inert 唔受支援時仍有停用控制同狀態保護。
紀念卡固定 1200 × 1800（2.16 百萬像素），唔會再乘 Retina DPR。
景觀用可重用嘅暫存畫布，避免輸入稱呼時累積 Canvas 記憶體。
唔同系統會用本機字型，因此文字排版可能有少少分別。
部分手機、內嵌瀏覽器或檔案預覽器可能唔會直接下載 PNG；
直接用頁面提供嘅圖片保存方式。
相片選單由 iOS／微信控制；網頁唔可以靜默寫入相簿或繞過系統限制。
冇測試真實 iPhone／Android 裝置或 Safari，唔保證所有檔案預覽器可用。
